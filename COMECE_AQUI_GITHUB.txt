 🚀 EU VOU COM A OPÇÃO 1 (GitHub Desktop)

═══════════════════════════════════════════════════════════════════════════════

 Se escolheu a Opção 1, siga estes passos:

 PASSO 1: Baixar GitHub Desktop
 ──────────────────────────────
 1. Acesse: https://desktop.github.com
 2. Clique "Download for Windows"
 3. Instale (Next > Next > Finish)
 4. Abra GitHub Desktop


 PASSO 2: Fazer Login
 ──────────────────
 1. No GitHub Desktop, clique "Sign in to GitHub.com"
 2. Clique "Sign in with your browser"
 3. Faça login no GitHub
    (Crie conta se não tiver em: https://github.com/signup)
 4. Clique "Authorize desktop"


 PASSO 3: Adicionar Projeto
 ─────────────────────────
 1. GitHub Desktop → File → Add Local Repository
 2. Clique "Browse"
 3. Navegue até: C:\Users\User\OneDrive\Imagens\Claude Code
 4. Clique "Select Folder"
 5. Se pedir, clique "Initialize"


 PASSO 4: Publicar no GitHub
 ───────────────────────────
 1. Clique "Publish repository" (no topo)
 2. Preencha:
    ├─ Name: pdv-system
    ├─ Description: PDV System com PIX
    └─ Private: (deixe marcado para seguro)
 3. Clique "Publish Repository"
 4. Aguarde 30-60 segundos


 PASSO 5: Fazer Commit
 ────────────────────
 1. GitHub Desktop mostra os arquivos novos
 2. Em "Summary" escreva:
    "PDV System v1.3 com PIX integrado"
 3. Clique "Commit to main"


 PASSO 6: Fazer Push (Enviar)
 ─────────────────────────────
 1. Clique "Push origin" (no topo)
 2. Aguarde alguns segundos
 3. Pronto! Código no GitHub!
