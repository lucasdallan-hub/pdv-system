 🚨 SE ALGO DER ERRADO

═══════════════════════════════════════════════════════════════════════════════

 ERRO: "Build failed"
 ─────────────────
 Solução:
 1. Verifique os logs no Railway
 2. Certifique-se que `npm run build` funciona local
 3. Faça novo commit e push

 ERRO: "Cannot find module"
 ────────────────────────
 Solução:
 1. Verifique package.json
 2. Execute `npm install` localmente
 3. Commit o arquivo package-lock.json
 4. Push e redeploy

 ERRO: "Port 5000 in use"
 ──────────────────────
 Solução:
 1. Railway automaticamente ajusta porta
 2. Verifique variável PORT nas settings

 ERRO: "DATABASE_URL not set"
 ────────────────────────────
 Solução:
 1. No Railway, vá em "Add Service"
 2. Selecione "PostgreSQL"
 3. Aguarde ser criado
 4. DATABASE_URL será auto-configurado
