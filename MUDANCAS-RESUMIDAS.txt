 1️⃣ OPÇÃO DE DELETAR (🗑️)

═══════════════════════════════════════════════════════════════════════════════

  Adicionado em TODAS as telas:

  ✅ Vendas     → Clique em 🗑️ para deletar uma venda
  ✅ Recebimentos → Clique em 🗑️ para deletar recebimento
  ✅ Pagamentos  → Clique em 🗑️ para deletar pagamento
  ✅ Clientes   → Clique em 🗑️ para deletar cliente

  Como usar:
  1. Procure a linha que quer deletar
  2. Clique no ícone 🗑️ (trash) à direita
  3. Confirme se tem certeza
  4. Deletado! ✓


═══════════════════════════════════════════════════════════════════════════════

 2️⃣ LANÇAMENTO RÁPIDO (⚡ NOVO BOTÃO)

═══════════════════════════════════════════════════════════════════════════════

  Novo botão FLUTUANTE no canto inferior direito:

  🟢 Clique no + verde

  3 opções aparecem:

  🛒 VENDA RÁPIDA
     - Cliente
     - Descrição do produto
     - Valor
     - REGISTRAR

  💰 RECEBIMENTO
     - Cliente
     - Descrição
     - Valor
     - Data de vencimento
     - REGISTRAR

  📊 PAGAMENTO
     - Descrição
     - Valor
     - Data de vencimento
     - REGISTRAR

 📝 EXEMPLOS

  Registrar venda rápido:
  ──────────────────────

  2. Selecione "Venda Rápida"
  3. Cliente: João
  4. Produto: Camiseta
  5. Valor: 50.00
  6. Clique "Registrar"
  7. Venda criada em 5 segundos!
