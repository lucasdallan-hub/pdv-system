 ⚠️  IMPORTANTE - LEIA ANTES DE COMEÇAR

═══════════════════════════════════════════════════════════════════════════════

A Vercel funciona melhor com FRONTEND. Para usar com BACKEND (Node.js):

OPÇÃO A - Recomendado (Separado):
├─ Frontend → Vercel ✅ (perfeito, rápido, grátis)
├─ Backend → Railway ✅ (já está configurado)
└─ Ambos comunicam via API

OPÇÃO B - Monorepo (Mais complexo):
├─ Frontend + Backend → Vercel
└─ Precisa de banco de dados PostgreSQL na Vercel

👉 Vamos fazer OPÇÃO A (Frontend no Vercel + Backend no Railway)


═══════════════════════════════════════════════════════════════════════════════

 PASSO 1: PREPARAR O GITHUB

═══════════════════════════════════════════════════════════════════════════════

Você já tem o código no GitHub! ✅

Repositório: https://github.com/lucasdallan-hub/pdv-system


═══════════════════════════════════════════════════════════════════════════════

 PASSO 2: CRIAR CONTA NA VERCEL

═══════════════════════════════════════════════════════════════════════════════

1. Acesse: https://vercel.com

2. Clique "Sign Up"

3. Escolha "Continue with GitHub"

4. Autorize a Vercel acessar sua conta GitHub

5. Pronto! Conta criada ✅


═══════════════════════════════════════════════════════════════════════════════

 PASSO 3: CRIAR NOVO PROJETO NA VERCEL

═══════════════════════════════════════════════════════════════════════════════

1. Na dashboard da Vercel, clique "Add New..." → "Project"

2. Você verá seus repositórios do GitHub

3. Procure: "pdv-system"

4. Clique "Import"


═══════════════════════════════════════════════════════════════════════════════

 PASSO 4: CONFIGURAR O PROJETO

═══════════════════════════════════════════════════════════════════════════════

A Vercel vai mostrar uma tela de configuração:

┌─────────────────────────────────────┐
│ Project Name: pdv-system-frontend   │
│ Framework: Create React App          │
│ Root Directory: ./frontend           │
│ Build Command: npm run build         │
│ Output Directory: build              │
└─────────────────────────────────────┘

Ajuste assim:
├─ Project Name: pdv-system-frontend
├─ Framework: Other (ou deixa automático)
├─ Root Directory: ./frontend
├─ Build Command: npm run build
└─ Output Directory: build


═══════════════════════════════════════════════════════════════════════════════

 PASSO 5: VARIÁVEIS DE AMBIENTE

═══════════════════════════════════════════════════════════════════════════════

Você vai ver uma seção "Environment Variables"

Adicione:

┌──────────────────────────────────────────────────────┐
│ REACT_APP_API_URL=https://seu-backend.railway.app   │
│ (Este é o URL do seu backend no Railway!)           │
└──────────────────────────────────────────────────────┘

Se não sabe a URL do Railway:
1. Acesse: https://railway.app
2. Clique no seu projeto "pdv-system"
3. Copie a URL que aparece no topo
4. Cole aqui


═══════════════════════════════════════════════════════════════════════════════

 PASSO 6: FAZER DEPLOY

═══════════════════════════════════════════════════════════════════════════════

1. Clique o botão grande "Deploy"

2. Aguarde (leva 1-3 minutos)

3. Quando terminar:
   ├─ Você vê um botão "Visit"
   └─ Clique para acessar seu PDV! 🎉

═══════════════════════════════════════════════════════════════════════════════

 🔗 CONECTAR COM DOMÍNIO PRÓPRIO

═══════════════════════════════════════════════════════════════════════════════

Se quer usar seu domínio (meussistema.com.br):

1. Compre domínio em: Registro.br, GoDaddy, etc

2. Na Vercel, vá ao seu projeto

3. Clique "Settings" → "Domains"

4. Cole seu domínio: meussistema.com.br

5. Vercel fornece nameservers

6. Mude os nameservers no registrador (onde comprou domínio)

7. Aguarde 24-48h para propagar


═══════════════════════════════════════════════════════════════════════════════

 ❌ SE DER ERRO - SOLUÇÃO RÁPIDA

═══════════════════════════════════════════════════════════════════════════════

ERRO: "npm run build falha"
├─ Solução: Cheque se frontend/package.json tem react-scripts
└─ Execute localmente: cd frontend && npm install

ERRO: "404 - Página não encontrada"
├─ Solução: Adicione REACT_APP_API_URL no Environment Variables
└─ Redeploy o projeto

ERRO: "API não conecta"
├─ Solução: Atualize REACT_APP_API_URL com URL certo do backend
└─ Cheque se o URL do Railway está correto

ERRO: "Build timeout"
├─ Solução: Vercel tem limite de build
├─ Apague pasta frontend/node_modules localmente
├─ Faça novo push no GitHub
└─ Deixa Vercel instalar do zero
