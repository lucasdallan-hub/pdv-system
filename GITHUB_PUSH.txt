 🖥️ OPÇÃO 1: GITHUB DESKTOP (Mais Fácil - Recomendado!)

═══════════════════════════════════════════════════════════════════════════════

 PASSO 1: Baixar GitHub Desktop
 ──────────────────────────────

 1. Acesse: https://desktop.github.com
 2. Clique em "Download for Windows"
 3. Instale normalmente (Next > Next > Finish)
 4. Abra GitHub Desktop


 PASSO 2: Fazer Login
 ────────────────────

 1. Menu: File → Options
 2. Clique em "Sign in"
 3. Escolha "Sign in with browser"
 4. Autorize o GitHub
 5. Confirme no navegador
 6. Volte para GitHub Desktop


 PASSO 3: Adicionar Repositório Local
 ────────────────────────────────────

 1. Menu: File → Add Local Repository
 2. Clique "Choose"
 3. Navegue até: C:\Users\User\OneDrive\Imagens\Claude Code
 4. Selecione a pasta
 5. Clique "Add Repository"
 6. Preencha:
    ├─ Name: pdv-system
    ├─ Description: PDV System com PIX e WhatsApp
    └─ Local Path: (já preenchido)
 7. Clique "Create Repository & Publish"


 PASSO 4: Publicar no GitHub
 ───────────────────────────

 GitHub Desktop vai mostrar:

 ┌────────────────────────────────────┐
 │ Publish repository                  │
 ├────────────────────────────────────┤
 │ Name: pdv-system                    │
 │ Description: (conforme acima)       │
 │ [✓] Keep this code private          │
 │ [Publish Repository]                │
 └────────────────────────────────────┘

 Clique "Publish Repository"
 Aguarde... (30-60 segundos)


 PASSO 5: Fazer Commit e Push
 ────────────────────────────

 Após publicar, você verá mudanças pendentes:

 ┌────────────────────────────────────┐
 │ Summary: "Inicial commit"           │ ← Descreva o que mudou
 │ Description: (opcional)             │
 │                                     │
 │ [Commit to main]                    │ ← Clique aqui
 └────────────────────────────────────┘

 Depois:

 ┌────────────────────────────────────┐
 │ [Push origin]                       │ ← Clique para enviar
 └────────────────────────────────────┘

 ✅ Pronto! Código está no GitHub!


═══════════════════════════════════════════════════════════════════════════════

 ⌨️ OPÇÃO 2: LINHA DE COMANDO (Terminal)

═══════════════════════════════════════════════════════════════════════════════

 PASSO 1: Abrir PowerShell como Admin
 ────────────────────────────────────

 1. Aperte: Windows + X
 2. Selecione "Windows PowerShell (Admin)"
 3. Clique "Sim" na confirmação


 PASSO 2: Navegar até Projeto
 ────────────────────────────

 cd "C:\Users\User\OneDrive\Imagens\Claude Code"


 PASSO 3: Configurar Git (Primeira vez apenas)
 ──────────────────────────────────────────────

 git config --global user.name "Seu Nome Completo"
 git config --global user.email "seu.email@github.com"


 PASSO 4: Inicializar Repositório
 ─────────────────────────────────

 git init
 git add .
 git commit -m "PDV System pronto para Railway"
 git branch -M main


 PASSO 5: Criar Repositório no GitHub
 ────────────────────────────────────

 1. Abra: https://github.com/new
 2. Preencha:
    ├─ Repository name: pdv-system
    ├─ Description: PDV System com PIX
    ├─ Select: Public (ou Private)
    └─ [Create repository]


 PASSO 6: Conectar e Fazer Push
 ──────────────────────────────

 No PowerShell, execute:

 git remote add origin https://github.com/SEU_USUARIO/pdv-system.git
 git push -u origin main

 Substitua SEU_USUARIO por seu username do GitHub!

 Você pode achar seu username em:
 GitHub.com → Profile (canto superior direito)


 PASSO 7: Confirmar
 ──────────────────

 ✅ Se não houver erro, código foi enviado!
 ✅ Acesse: https://github.com/seu-usuario/pdv-system

 🔄 FAZER PUSH DE ATUALIZAÇÕES (Depois)

═══════════════════════════════════════════════════════════════════════════════

 COM GITHUB DESKTOP:
 ──────────────────

 1. Faça mudanças no código
 2. Abra GitHub Desktop
 3. Vá em "Changes"
 4. Escreva resumo em "Summary"
    Exemplo: "Adicionado PIX"
 5. Clique "Commit to main"
 6. Clique "Push origin" (no topo)

 ✅ Pronto! Mudanças foram para GitHub!


 VIA LINHA DE COMANDO:
 ────────────────────

 cd "C:\Users\User\OneDrive\Imagens\Claude Code"

 git add .
 git commit -m "Descrição do que mudou"
 git push origin main

 ✅ Pronto! Mudanças foram para GitHub!

 ❓ DÚVIDAS FREQUENTES

═══════════════════════════════════════════════════════════════════════════════

 P: Qual opção escolho?
 R: GitHub Desktop é mais fácil (clica com mouse)
    Terminal é mais rápido depois que aprende

 P: Perdi meu token do GitHub?
 R: Não precisa! GitHub Desktop pede autorização no navegador

 P: Deu erro no git?
 R: Verifique:
    1. GitHub Desktop ou Git estão instalados?
    2. Você está logado no GitHub?
    3. Caminho da pasta está correto?

 P: Código aparece como "draft"?
 R: Normal! Clique "Publish repository" ou "Commit"

 P: .env vai ser enviado?
 R: NÃO! .gitignore protege arquivos sensíveis
    Railway vai configurar via Dashboard
