 🚀 PRÓXIMOS PASSOS (3 PASSOS SIMPLES!)

═══════════════════════════════════════════════════════════════════════════════

 PASSO 1: Colocar Código no GitHub (5 min)
 ──────────────────────────────────────

 Opção A (GitHub Desktop - Mais Fácil):

 1. Baixe: https://desktop.github.com
 2. Instale e faça login
 3. File → Add Local Repository
 4. Selecione: C:\Users\User\OneDrive\Imagens\Claude Code
 5. Clique "Create Repository & Publish"
 6. Clique "Publish Repository"

 OU

 Opção B (PowerShell):

 1. Abra PowerShell como Admin
 2. Execute os comandos em: GITHUB_PUSH.txt


 PASSO 2: Deploy no Railway (3 min)
 ──────────────────────────────────

 1. Acesse: https://railway.app
 2. Clique "Start a New Project"
 3. "Deploy from GitHub"
 4. Conecte sua conta GitHub
 5. Selecione repositório "pdv-system"
 6. Aguarde deploy (3-5 min)
 7. Railway mostra: https://seu-projeto.up.railway.app


 PASSO 3: Configurar Variáveis (2 min)
 ────────────────────────────────────

 1. Railway → Seu Projeto → Settings → Variables
 2. Adicione:
    ├─ PORT=5000
    ├─ NODE_ENV=production
    ├─ WUZAPI_URL=https://api.wuzapi.com
    ├─ WUZAPI_TOKEN=seu_token
    └─ WUZAPI_INSTANCE=sua_instancia
 3. Salve
 4. Railway redeploy automaticamente
